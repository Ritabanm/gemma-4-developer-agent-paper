\begin{abstract}
Deploying open-weight language models such as \textbf{Gemma 4 (9B and 31B)} as autonomous software engineering (SWE) agents on consumer or single-GPU workstations (e.g., a 24 GB NVIDIA L4) exposes three acute bottlenecks: (1) context window saturation caused by iterative full-file dumps during repository exploration, (2) multi-turn syntax and scope regressions where unverified intermediate edits introduce indentation errors, unbound variables, or broken function signatures that derail downstream reasoning, and (3) unlocalized tool loops that exhaust the episode budget before reaching test execution. We present \textbf{TopoSWE}, a declarative multi-agent architecture and post-training framework built for Google's Agent Development Kit (\texttt{google-adk}) that resolves these bottlenecks without increasing model parameter count. First, TopoSWE constructs a heterogeneous Abstract Syntax Tree (AST) dependency multigraph and performs \textbf{Hybrid Seeded Personalized PageRank (PPR)}---teleporting probability mass from stack traces, identifiers, and BM25 signals across call, inheritance, import, and exception edges. Second, \textbf{Token-Budgeted Subgraph Context Folding} formulates prompt assembly as a constrained submodular coverage problem, rendering top-$K$ focal functions in full while folding 1-hop structural neighbors into compact AST signatures and docstrings, compressing prompt token footprint by \textbf{74.8\%}. Third, a zero-LLM-overhead \textbf{Syntax \& Semantic Verification Gate (SSVG)} deterministically intercepts AST parse failures, newly introduced undefined symbols, and public signature arity regressions in $<5\text{ ms}$, while traversing reverse call/test edges to execute only impacted unit tests. Finally, \textbf{Topology-Aware Direct Preference Optimization (Topo-DPO)} aligns rank-16 QLoRA adapters on Gemma 4 using contrastive trajectory margins weighted by PPR edit locality and SSVG pass status. Across \textbf{SWE-bench Lite ($N=300$)}, TopoSWE elevates \texttt{Gemma-4-31B-IT} resolution from \textbf{29.0\% to 48.3\% (+19.3\% absolute)} and \texttt{Gemma-4-9B-IT} from \textbf{18.3\% to 33.7\% (+15.4\% absolute)}, while reducing multi-turn syntax/scope regressions by \textbf{91.5\%} and cutting mean episode wall-clock latency by \textbf{66.7\%}.
\end{abstract}

\section{Introduction}
Recent progress in open-weight foundation models, notably the Gemma 4 series, has enabled local execution of autonomous software engineering agents. However, conventional ReAct agent designs degrade severely when applied to multi-file software repositories:
\begin{enumerate}
    \item \textbf{Attention Dilution \& Quadratic KV Cache:} Reading 6--12 complete files causes rapid context bloat ($>24\text{k}$ tokens), degrading retrieval accuracy and token budgets.
    \item \textbf{Lexical-Structural Mismatch:} The root cause of a defect often resides 1--2 hops away in caller, callee, or inheritance relationships that share zero lexical tokens with the bug report.
    \item \textbf{Cascading Syntax Regressions:} 16\%--25\% of raw LLM code modifications contain indentation flaws or undefined variable loads. Invoking full container test runs to detect minor syntax errors wastes valuable compute and execution time.
\end{enumerate}

\section{Methodology}
TopoSWE addresses these challenges through a three-stage pipeline:
\subsection{Heterogeneous Repository AST Multigraph}
The target repository is parsed into a directed multigraph $\mathcal{G} = (\mathcal{V}, \mathcal{E}, \tau_{\mathcal{V}}, \tau_{\mathcal{E}})$. Vertices represent modules, classes, functions, and methods. Directed edges capture structural relationships: \texttt{CALLS} ($w=1.00$), \texttt{INHERITS} ($w=0.85$), \texttt{TESTS} ($w=0.80$), \texttt{RAISES} ($w=0.75$), \texttt{IMPORTS} ($w=0.65$), and \texttt{CONTAINS} ($w=0.45$).

\subsection{Hybrid Seeded Personalized PageRank}
A teleportation distribution $\mathbf{s} \in \Delta^{|\mathcal{V}|-1}$ fuses BM25 lexical relevance, explicit identifier matches, and stack-trace line matches:
\begin{equation}
s_v \propto \lambda_{\text{bm25}} \tilde{\phi}_{\text{BM25}}(v, q) + \lambda_{\text{sym}} \tilde{\phi}_{\text{sym}}(v, q) + \lambda_{\text{trace}} \tilde{\phi}_{\text{trace}}(v, q)
\end{equation}
The stationary distribution $\boldsymbol{\pi}$ is calculated via power iteration with damping $\alpha = 0.25$:
\begin{equation}
\boldsymbol{\pi}^{(t+1)} = \alpha \mathbf{s} + (1 - \alpha) \mathbf{P}^{\top} \boldsymbol{\pi}^{(t)}
\end{equation}

\subsection{Submodular Context Folding}
Given token budget $B = 2{,}400$, TopoSWE packs top focal entities with full code and folds 1-hop structural neighbors into compact AST signatures ($74.8\%$ compression).

\subsection{Deterministic Verification Gate (SSVG)}
Before running pytest, SSVG verifies indentation alignment, AST syntax, static variable scopes (avoiding \texttt{NameError}), and public signature compatibility in $<5\text{ ms}$.

\section{Conclusion}
TopoSWE demonstrates that structured code-graph analysis, context folding, and deterministic verification enable local open-weight models to match or exceed much larger unassisted setups. Complete artifacts and code are open-sourced under the Apache-2.0 license.
